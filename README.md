# Vizmoe Extras

## How do I install these formulae?

`brew install vizmoe/extras/<formula>`

Or `brew tap vizmoe/extras` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "vizmoe/extras"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
